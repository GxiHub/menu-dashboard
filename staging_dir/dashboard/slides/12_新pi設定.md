## 二、設定順序 Checklist

### Step 1 — 燒錄系統

```
使用 Raspberry Pi Imager 燒錄 Raspberry Pi OS Lite (64-bit)
設定頁面（齒輪）：
  ✅ hostname: pi51
  ✅ 啟用 SSH（使用 public key 驗證）
  ✅ 貼上 ~/.ssh/id_ed25519.pub 內容
  ✅ 設定 Wi-Fi SSID / 密碼
  ✅ 語系: Asia/Taipei, zh_TW.UTF-8
```

### Step 2 — 首次 SSH 連線

```bash
# 用 IP 直接連（DHCP 先從路由器查詢 IP）
ssh pi51@192.168.1.xxx

# 確認架構
uname -m          # 應為 aarch64
python3 --version # 應為 3.11+
```

### Step 3 — 系統更新

```bash
sudo apt-get update -y && sudo apt-get upgrade -y
sudo apt-get install -y git python3-pip python3-venv curl
```

### Step 4 — 安裝 Tailscale

```bash
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up
# 瀏覽器開啟授權連結，加入 tfooddata 帳號
sudo tailscale ip -4   # 記錄 Tailscale IP
```

### Step 5 — 加入 MacBook SSH config

在 MacBook `~/.ssh/config` 新增：

```
Host pi51
    HostName <Tailscale IP>
    User pi51
    IdentityFile ~/.ssh/id_ed25519
    ServerAliveInterval 60

Host pi51-local
    HostName 192.168.1.xxx
    User pi51
    IdentityFile ~/.ssh/id_ed25519
    ServerAliveInterval 60
```

### Step 6 — 安裝 Python 套件

```bash
pip3 install flask pyserial --break-system-packages
# RS485/Modbus 用途：
pip3 install minimalmodbus --break-system-packages
```

### Step 7 — 建立 Flask 服務目錄

```bash
# 參考 pi52 架構
sudo mkdir -p /var/www/html
sudo chown pi51:pi51 /var/www/html
cd /var/www/html && git init
```

### Step 8 — 建立 systemd 服務

```bash
sudo nano /etc/systemd/system/pi51-app.service
```

```ini
[Unit]
Description=Pi51 Flask App
After=network.target

[Service]
User=pi51
WorkingDirectory=/var/www/html
ExecStart=/usr/bin/python3 app.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable pi51-app
sudo systemctl start pi51-app
```

### Step 9 — Kiosk 模式（選配，有螢幕才需要）

```bash
sudo apt-get install -y chromium-browser unclutter
# /etc/xdg/lxsession/LXDE-pi/autostart 加入：
# @chromium-browser --kiosk --noerrdialogs http://localhost:5000
```

### Step 10 — RS485 設定（選配，有 RS485 裝置才需要）

```bash
# 確認 USB-RS485 裝置
ls /dev/ttyUSB*   # 通常是 /dev/ttyUSB0

# 建立 symlink（udev rule）
sudo nano /etc/udev/rules.d/99-rs485.rules
# SUBSYSTEM=="tty", ATTRS{idVendor}=="1a86", ATTRS{idProduct}=="7523", SYMLINK+="ttyRS485"
sudo udevadm control --reload-rules
```

**中盛科技新模組上線流程：**

| 步驟 | 動作 |
|------|------|
| Step A | 以 38400 baud 連 → 寫 reg 0x0033=1（改為 9600）→ 斷電重啟 |
| Step B | 以 9600 baud 連  → 寫 reg 0x0032=目標地址 → 斷電重啟 |
| Step C | 掃描 bus 確認有回應 |

## 五、常用遠端指令

```bash
# 查看服務狀態
ssh pi51 "systemctl status pi51-app"

# 即時 log
ssh pi51 "journalctl -u pi51-app -f --no-pager"

# 重啟服務
ssh pi51 "sudo systemctl restart pi51-app"

# 部署新版本
scp app.py pi51:/var/www/html/app.py && ssh pi51 "sudo systemctl restart pi51-app"

# 查 RS485 裝置
ssh pi51 "ls /dev/ttyUSB* /dev/ttyRS485 2>/dev/null"
```
