## 二、pi54 設定記錄（2026-04-20）

| 項目 | 內容 |
|------|------|
| 機器名稱 | `pi54` |
| 區域 IP | `192.168.1.125` |
| Tailscale IP | `100.70.170.115` |
| 作業系統 | Debian GNU/Linux 13 (Trixie) |
| 型號 | Raspberry Pi 4 |
| Python | 3.13.5 |
| 記憶體 | 4 GB |
| 磁碟 | 6.6 GB（88% 使用，注意空間） |
| 用途 | POS / RS485 節點 |
| 初始密碼 | `123456`（已加 SSH key，不需密碼） |

### 設定步驟

```bash
# 1. 用 sshpass 登入並加 SSH key（初次，沒有 key 的情況）
sshpass -p '123456' ssh pi54@192.168.1.125 \
  "mkdir -p ~/.ssh && echo '<public_key>' >> ~/.ssh/authorized_keys"

# 2. 安裝 Tailscale
curl -fsSL https://tailscale.com/install.sh -o /tmp/install_ts.sh
sudo bash /tmp/install_ts.sh
sudo tailscale up --hostname=pi54
# 瀏覽器授權連結

# 3. Flask app + /api/pi_info
# 放在 /home/pi54/app.py
# 開機服務：/etc/systemd/system/pi54-app.service
sudo systemctl enable pi54-app
sudo systemctl start pi54-app
```

### pi54 systemd service

```ini
[Unit]
Description=pi54 Flask App
After=network.target

[Service]
User=pi54
WorkingDirectory=/home/pi54
ExecStart=/usr/bin/python3 /home/pi54/app.py
Restart=always

[Install]
WantedBy=multi-user.target
```

## 三、印表機設定記錄（Epson TM-m30 系列）

| 項目 | 內容 |
|------|------|
| 印表機 IP | `192.168.1.124`（DHCP，可能變動） |
| 連線 Port | `9100` |
| WebConfig URL | `http://192.168.1.124` |
| 查 IP 方式 | 按 Feed 鍵印出狀態頁 |

### ⚠️ 重要：列印架構

```
POS (pi53:5011)
    → pi52:5000/api/print_receipt
        → proxy.py localhost:9200   ← 只能走這條
            → 印表機:9100
```

**絕對不能** 直接從 app.py 連 `192.168.1.124:9100`，因為 proxy.py 已佔住該連線（Epson 只允許一條 TCP）。

### proxy.py 關鍵設定

```python
PRINTER_IP   = "192.168.1.124"   # 印表機 IP（如換 IP 要改這裡）
PRINTER_PORT = 9100
# proxy.py 監聽：
#   0.0.0.0:9100  → 接收外部（UberEats 平板）
#   127.0.0.1:9200 → 接收 app.py 的列印請求（本機）
```

### print_receipt 正確設定

```python
# /var/www/html/app.py（pi52）
PRINT_HOST = '127.0.0.1'   # 走 proxy.py
PRINT_PORT = 9200           # proxy local server port
```

### 常見問題

| 症狀 | 原因 | 解法 |
|------|------|------|
| 按列印沒反應 | print_receipt 回 200 但不出單 | 確認 proxy.py 在跑且連線正常 |
| proxy.py 一直 timeout | 印表機閒置斷線 | 重開印表機或等 proxy 重連（約 5 秒一次） |
| WebConfig 連不上 | proxy.py 佔住 port 9100 | kill proxy.py → 操作 WebConfig → 重啟 proxy.py |
| 印出 WebConfig 狀態頁 | 開機時按到 Feed 鍵 | 正常開機即可，不影響列印 |

## 四、新 Pi 設定 Checklist

### Step 1 — 燒錄系統

```
使用 Raspberry Pi Imager 燒錄 Raspberry Pi OS Lite (64-bit)
設定：
  ✅ hostname: piXX
  ✅ 啟用 SSH（public key 驗證）
  ✅ Wi-Fi SSID / 密碼
  ✅ 語系: Asia/Taipei
```

### Step 2 — 加入 SSH key（若沒有 key）

```bash
sshpass -p '<密碼>' ssh piXX@<IP> \
  "mkdir -p ~/.ssh && chmod 700 ~/.ssh && \
   echo '<public_key>' >> ~/.ssh/authorized_keys && \
   chmod 600 ~/.ssh/authorized_keys"
```

### Step 3 — 安裝 Tailscale

```bash
curl -fsSL https://tailscale.com/install.sh -o /tmp/install_ts.sh
sudo bash /tmp/install_ts.sh
sudo tailscale up --hostname=piXX
# 瀏覽器授權（https://login.tailscale.com/a/xxxxxx）
```

### Step 4 — 加入 MacBook SSH config

```
Host piXX
    HostName <local IP>
    User piXX
    IdentityFile ~/.ssh/id_ed25519
    ServerAliveInterval 60

Host piXX-ts
    HostName <Tailscale IP>
    User piXX
    IdentityFile ~/.ssh/id_ed25519
    ServerAliveInterval 60
```

### Step 5 — 建立 Flask app + /api/pi_info

```bash
# 放 app.py 到 /home/piXX/
# 參考 pi54/app.py 模板
```

### Step 6 — 建立 systemd 服務

```bash
sudo tee /etc/systemd/system/piXX-app.service << EOF
[Unit]
Description=piXX Flask App
After=network.target
[Service]
User=piXX
WorkingDirectory=/home/piXX
ExecStart=/usr/bin/python3 /home/piXX/app.py
Restart=always
[Install]
WantedBy=multi-user.target
EOF
sudo systemctl daemon-reload
sudo systemctl enable piXX-app
sudo systemctl start piXX-app
```

### Step 7 — 登記到 pi53 pi_nodes.json

```bash
# 編輯 /home/pi53/dashboard-v2/pi_nodes.json
# 加入新節點資訊
```

### Step 8 — 驗收

```bash
# MacBook → pi53 查詢新節點
curl http://100.69.230.13/api/pi_network/status
# 確認新節點出現且 /api/pi_info 有回應
```

## 五、RS485 設定（有裝置才需要）

```bash
ls /dev/ttyUSB*   # 確認 USB-RS485 轉換器

# udev rule（讓裝置名固定）
sudo tee /etc/udev/rules.d/99-rs485.rules << EOF
SUBSYSTEM=="tty", ATTRS{idVendor}=="1a86", ATTRS{idProduct}=="7523", SYMLINK+="ttyRS485"
EOF
sudo udevadm control --reload-rules
```

**中盛科技新模組設定流程：**

| 步驟 | 動作 |
|------|------|
| Step A | 38400 baud → 寫 reg 0x0033=1（改 9600）→ 斷電重啟 |
| Step B | 9600 baud → 寫 reg 0x0032=目標地址 → 斷電重啟 |
| Step C | 掃描 bus 確認有回應 |
