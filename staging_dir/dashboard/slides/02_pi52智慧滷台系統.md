## 三、RS485 裝置配置

### 繼電器通道對照

| 功能 | 模組 | Coil | 備註 |
|------|------|------|------|
| 推桿 1 伸/縮 | 0x0B | 0 / 1 | FC05 |
| 推桿 2 伸/縮 | 0x0B | 2 / 3 | |
| 推桿 3 伸/縮 | 0x0B | 4 / 5 | |
| 風扇 1 | 0x0B | 6 | 手動 |
| 風扇 2 | 0x0B | 7 | 手動 |
| 推桿 6 伸/縮 | 0x0C | 0 / 1 | |
| 風扇 3 | 0x0C | 4 | **自動溫控連動** |
| 推桿 4/5 | 0x0C | 6 / 7 | |

### 中盛科技模組規格

| 項目 | 出廠預設 | pi52 系統 |
|------|---------|----------|
| 波特率 | **38400** | **9600** |
| 資料位/停止位 | 8 / 1 | 8 / 1 |

**關鍵暫存器（FC06，掉電保存，重啟生效）：**

| 暫存器 | 功能 |
|--------|------|
| `0x0032` | RS485 地址（1~255） |
| `0x0033` | 波特率：0=4800 / **1=9600** / 4=38400 |

**PT100 讀溫度（FC04）：** reg `0x0000` = CH1，最高位=符號，÷10 = °C，`0xFFFF` = 斷路

**繼電器（FC05）：** `FF00` = ON，`0000` = OFF，Coil 從 0 開始

## 四、自動溫控邏輯

### 四段式控溫

| 階段 | 條件 | 功率 |
|------|------|------|
| 加熱（低段） | T < 89°C | 65% |
| 加熱（衝刺） | 89°C ≤ T < 100°C | 70% |
| 保溫 | T ≥ 100°C | 40% |
| 保溫補熱 | 保溫中 T < 93°C | 70% |

最高功率硬限制：`AUTO_MAX_PWR = 78%`

### 一鍵加熱流程

```
設定水量（0.5L ~ 30L）→ 按「▶ 開始」
    ↓
清除舊曲線 → 自動溫控 ON → 風扇 3 ON → 計時器啟動
    ↓
達到 100°C → 自動溫控 OFF → 風扇 OFF → 計時器停止
```

### 自動化料理流程

```
🔥 加熱湯鍋 → 🧺 放入食材 → ⬇ 推桿下降
                                    │
✅ 完成料理 ← ⬆ 推桿升起 ← ⏱ 浸泡計時
```

## 七、新模組上線 SOP

> ⚠️ 出廠波特率 38400，系統用 9600，新模組插上 bus 不會有回應。單獨接線設定。

```
Step 1　38400 baud → 寫 reg 0x0033=1（改 9600）→ 斷電重啟
Step 2　9600 baud  → 寫 reg 0x0032=目標地址    → 斷電重啟
Step 3　掃描 bus 確認回應
```

```python
import serial, struct, time

def crc16(data):
    crc = 0xFFFF
    for b in data:
        crc ^= b
        for _ in range(8):
            crc = (crc >> 1) ^ 0xA001 if crc & 1 else crc >> 1
    return crc

def fc06(ser, slave, reg, val):
    pkt = struct.pack('>BBHH', slave, 0x06, reg, val)
    pkt += struct.pack('<H', crc16(pkt))
    ser.reset_input_buffer()
    ser.write(pkt)
    time.sleep(0.4)
    resp = ser.read(8)
    ok = bool(resp and resp[0] == slave and resp[1] == 0x06)
    print(f'Slave 0x{slave:02X} reg 0x{reg:04X}={val} → {"OK" if ok else "FAIL"}')
    return ok

# Step 1：改波特率
ser = serial.Serial('/dev/ttyRS485', 38400, timeout=1)
fc06(ser, 0x01, 0x0033, 1)
ser.close()
input('斷電重啟後按 Enter...')

# Step 2：改地址
TARGET = 0x0C  # ← 修改為目標地址
ser = serial.Serial('/dev/ttyRS485', 9600, timeout=1)
fc06(ser, 0x01, 0x0032, TARGET)
ser.close()
```

## 八、排錯備忘

| 現象 | 原因 | 解法 |
|------|------|------|
| 新模組無回應 | 出廠 38400，系統 9600 | 先用 38400 改波特率 |
| 改地址後仍是舊地址 | 未斷電（軟重啟無效） | 拔插電源 |
| 掃描收到錯誤回應 | Bus 雜訊 | `reset_input_buffer()`，間隔 ≥ 0.3s |
| PT100 讀到 0xFFFF | 探針斷路 | 檢查 T+/T− 接線 |
| 繼電器 coil 編號混淆 | 0-indexed | Coil 1 = index 0 |
| 按列印沒反應 | proxy.py 斷線 | 確認 proxy.py 在跑 |
| proxy timeout | 印表機閒置斷線 | 重開印表機或等重連（~5s） |
