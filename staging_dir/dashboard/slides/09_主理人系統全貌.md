# 主理人效率餐飲系統

**Owner Efficiency Restaurant System**

**版本：** v2.0　｜　**建立：** 2026-04-21　｜　**合併自：** 09 主理人創業系統 + 15 系統 Rundown　｜　**狀態：** 🟢 核心已上線

> 一份文件：商業邏輯 + 系統架構 + 項目追蹤

---

## 一句話描述

> 透過**自動化設備、標準化流程、全流程數位化**，建立可複製的餐飲營運模型，讓主理人**收入翻倍，而不是工時翻倍**。

---

## 系統核心邏輯

```
餐飲主理人收入提升
│
├─ 單店雙品牌   ← 提升營收（一份租金、兩份收入）
├─ 自動化設備   ← 提升效率（不需要師傅）
├─ SOP 流程     ← 降低失誤（新人快速上手）
├─ 人力設計     ← 降低成本（可輪替、不依賴高技術）
└─ 數位化系統   ← 數據驅動（POS → KDS → 帳務 → CRM）
```

---

## 目標客群

**特徵：** 想創業或已創業、有營運能力但缺完整系統、不想被高額加盟綁死

| 痛點 | 現況 |
|------|------|
| 開店成功率低 | 90% 餐廳 1 年內倒閉 |
| 人力成本過高 | 人事佔營收 25-30% |
| 單品牌營收有限 | 店面時段利用率不到一半 |
| 營運依賴個人經驗 | 無法複製、無法休息 |

---

## 核心營運流程

```
📱 POS 點餐 → 📺 撿料站 KDS → 🍲 滷鍋站（自動升降）→ ✅ 出餐檢核 → 📊 數據回流
   │              │                │                    │              │
 開始計時      品項逐一確認       滷製+麵類確認         逐項打勾       Dashboard
 綁定電話      完成自動流轉       braised_at 記錄      防止漏裝       即時監控
```

每一站都留下時間戳記，全程可追蹤、可量化。

---

## 四大模組

### 模組一：開店風險降低

| 方法 | 內容 |
|------|------|
| SOP 系統 | 出餐/清潔/日常營運/設備操作，標準化流程 |
| 店內動線 | 食材單向流動、出餐最短路徑、備料區集中 |
| 半自動設備 | 自動升降煮台、標準化份量，降低技術依賴 |

### 模組二：營運效率提升

**人力設計：**

| 角色 | 職責 | 特點 |
|------|------|------|
| 煮台手 | 操作設備、控制出餐 | 設備輔助，低技術門檻 |
| 撿料手 | 備料、配料 | SOP 標準化，快速上手 |
| 收銀手 | 點餐、結帳 | 可由自助點餐部分取代 |

可輪替、不依賴高技術人員。

**數位化系統（已上線）：**

| 系統 | 狀態 | 價值 |
|------|------|------|
| POS 收銀台 | ✅ | 下單即計時，零漏單 |
| 撿料站 KDS | ✅ | 撿料零漏項 |
| 滷鍋站 KDS | ✅ | 麵類提醒，防漏備 |
| 出餐檢核站 | ✅ | 逐項確認，防漏裝 |
| 流程計時 | ✅ | 找出瓶頸站 |
| 客戶等候查詢 | ✅ | 掃 QR 查進度 |
| 手機掃碼點餐 | ✅ | 客人自助下單 |
| 系統監控 | ✅ | 52 項自動檢查 |
| 三層備份 | ✅ | JSONL + DB 快照 + rsync |
| 帳務損益 | ✅ | 日帳 + 月報 + 損益分析 |
| PIN 權限管理 | ✅ | 收銀員/店員/店長分級 |
| CRM 客戶管理 | 🔜 | 回購分析、精準行銷 |

### 模組三：單店營收放大

**核心策略：單店雙品牌**

| | 午餐品牌 | 晚餐品牌 |
|--|---------|---------|
| 品類 | 高翻桌（例：水餃） | 高毛利（例：滷味） |
| 時段 | 11:00-14:00 | 16:00-22:00 |
| 效果 | 時段利用率 40%→80%、坪效提升 60-75% |

共享：租金 + 設備 + 人力，外送平台雙品牌曝光 = 兩間店流量。

### 模組四：可複製模型

```
Phase 1（0-6月）      Phase 2（6-18月）     Phase 3（18月+）
─────────────        ─────────────        ─────────────
單店驗證              標準化輸出             規模化
• 測試菜單流程        • SOP 定版            • 設備租賃包
• 確認損益數據        • 供應鏈建立           • 營運系統授權
• 優化設備配置        • 培訓體系建立          • 更多主理人加入
```

---

## 商業模式

**系統提供：**
1. 自動化設備 — 降低技術門檻
2. 營運流程系統 — SOP + 動線 + 人力設計
3. 數位化平台 — POS + KDS + 帳務 + CRM
4. 雙品牌模型 — 營收結構設計

**收入來源：** 設備租賃費 + 系統服務費

> 系統收入建立在主理人成功的基礎上。主理人賺錢，系統才有收入。

## 數位化三層價值

| 層面 | 效果 |
|------|------|
| 效率面 | 全流程計時 → 找出瓶頸；各站螢幕 → 零喊單零漏單 |
| 經營面 | POS → 帳務自動入帳；電話 → CRM 回購；PIN 分級 → 權限管控 |
| 安全面 | 三層備份 + 52 項 E2E 測試 + Telegram 即時告警 |

## 願景

**現在：** 單店效率模型 — 跑通一間店的完整系統，證明可行可複製

**未來：** 可規模化的主理人創業系統 — 供應鏈整合、金融協助、創業支援

> 一切的基礎，是先把**單店效率模型**做到極致。
