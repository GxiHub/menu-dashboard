## MacBook SSH Config

```
# pi53 主控（Tailscale）
Host pi
    HostName 100.69.230.13
    User pi53
    IdentityFile ~/.ssh/id_ed25519
    ServerAliveInterval 10

# pi53 本地
Host pi5
    HostName 192.168.1.111
    User pi53
    IdentityFile ~/.ssh/id_ed25519
    ServerAliveInterval 60

# pi52（Tailscale）

    HostName 100.98.225.85
    User pi52
    IdentityFile ~/.ssh/id_ed25519
    ServerAliveInterval 60
```

## 標準化端點：`/api/pi_info`

每台 Pi 需實作此端點，供 pi53 Dashboard 的「Pi 網路」頁面自動輪詢：

```json
{
  "name": "pi51",
  "role": "待定",
  "model": "Raspberry Pi 3",
  "ip": {"local": "192.168.1.113", "tailscale": "100.118.76.98"},
  "ui_url": "http://100.118.76.98:5000",
  "services": [{"name": "pi51-app", "port": 5000, "status": "running"}],
  "uptime": "up 1 hour",
  "updated": "2026-04-18T00:00:00"
}
```

新增節點流程：在 pi53 的 `pi_nodes.json` 加入新節點設定，Dashboard 自動顯示。
