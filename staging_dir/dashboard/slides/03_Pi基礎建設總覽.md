## 二、Fleet 模組化部署系統

> pi53 為 master，統一管理並下放功能到各節點

### 架構

```
pi53 /home/pi53/raspi-system/fleet/
├── deploy.sh                     ← 主指令
├── modules/
│   └── printer-proxy/
│       ├── files/proxy.py        ← 從 pi52 抽出
│       ├── files/printer-proxy.service
│       └── post_deploy.sh        ← 自動修正 IP/MAC/DB、安裝 systemd
└── nodes/
    ├── pi52.conf  (100.98.225.85)
    ├── pi54.conf  (100.70.170.115)
    └── pi51.conf  (100.118.76.98)
```

### 使用方式

```bash
# 在 pi53 上執行
cd ~/raspi-system/fleet

./deploy.sh pi54 printer-proxy    # 部署單一模組
./deploy.sh pi51 printer-proxy    # 同一模組部署到另一節點
```

### post_deploy 自動處理

| 項目 | 說明 |
|------|------|
| placeholder 替換 | `__NODE_HOME__` / `__NODE_USER__` → 實際值 |
| DB 路徑修正 | `/var/www/html/orders.db` → `$HOME/orders.db` |
| IP/MAC 偵測 | 自動寫入 proxy.py |
| systemd 安裝 | daemon-reload + enable + restart |

### 工具組合

| 工具 | 角色 | 解決的問題 |
|------|------|-----------|
| Tailscale | 安全網路層 | 穿透 NAT／防火牆，不需開 port |

| 裝置 | 指令 | 特性 |

| Mac | `pi`（alias） | mosh + 自動 attach tmux session |

## 五、新 Pi 設定 SOP

```
Step 1 — 燒錄 Raspberry Pi OS Lite (64-bit)
         設定 hostname / SSH key / Wi-Fi / 語系

Step 2 — 加入 pi53 SSH key
         在 pi53 執行：ssh-copy-id piXX@<IP>

Step 3 — 設定 sudoers NOPASSWD
         echo "piXX ALL=(ALL) NOPASSWD:ALL" > /etc/sudoers.d/piXX-nopasswd

Step 4 — 安裝 Tailscale
         curl -fsSL https://tailscale.com/install.sh | sudo bash
         sudo tailscale up --hostname=piXX

Step 5 — 加入 fleet/nodes/piXX.conf

Step 6 — 部署所需模組
         cd ~/raspi-system/fleet && ./deploy.sh piXX <module>

Step 7 — 驗收
         curl http://100.69.230.13/api/pi_network/status
```

## 六、災難復原

### 你只需要兩樣東西

1. **一張新 SD 卡**（燒好 Raspberry Pi OS，user 設為 `pi53`）
2. **`secrets_backup.tar.gz`**（從密碼管理器取得）

### 兩條指令搞定

```bash
scp secrets_backup.tar.gz pi53@<new-pi-ip>:~/
ssh pi53@<new-pi-ip>
curl -fsSL https://raw.githubusercontent.com/GxiHub/raspi-dotfiles/main/restore_pi5.sh | bash
```
