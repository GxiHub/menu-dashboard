# Pi 節點架構規劃

**類型：** 系統設計　｜　**日期：** 2026-04-23　｜　**狀態：** 規劃中

---

## 目標

一間店一張 Pi，每間店 POS 不同，但品項管理、訂單歷史、帳務統一管理。

---

## 架構：Server + Worker 分層

```
pi53（中央 Server）
├── luwei-manager（POS 後端、品項管理、訂單 DB）
├── 帳務報表、KDS、dashboard
├── ubereats-sync（整合各店 UberEats 訂單）
└── fleet 管理（部署其他 Pi）

pi52（Worker：德光店）          pi54（Worker：另一間店）
├── printer-proxy               ├── printer-proxy
├── ocr_helper（GPT-4o）         ├── ocr_helper（GPT-4o）
├── orders.db（攔截記錄）         ├── orders.db
└── → 訂單資料送往 pi53           └── → 訂單資料送往 pi53
```

**POS 收銀方式：**
每間店的收銀平板/電腦開瀏覽器連到 `pi53:5011`（luwei-manager），不需要在每張 Pi 上各自跑一套 POS。

## pi52 完整設定清單（基準版本）

### 系統層
| 項目 | 設定方式 | 值 |
|------|---------|-----|
| 靜態 IP | nmcli | 192.168.1.109 |
| SSH 信任 pi53 | authorized_keys | pi53 ed25519 key |
| sudoers NOPASSWD | /etc/sudoers.d/ | pi52 ALL=(ALL) NOPASSWD:ALL |

### 服務層
| 服務 | 位置 | 說明 |
|------|------|------|
| printer-proxy.service | /etc/systemd/system/ | 開機自啟，重啟自動恢復 |
| 圖片目錄 | /var/www/html/static/orders/ | 攔截的收據 PNG |
| orders.db | /var/www/html/orders.db | 列印記錄 SQLite |

### 程式層
| 檔案 | 位置 | 說明 |
|------|------|------|
| proxy.py | /home/pi52/ | ENPC + ESC/POS 轉發 + 廣播上線通知 |
| ocr_helper.py | /home/pi52/ | GPT-4o Vision 解析收據 |
| .env | /home/pi52/ | OpenAI API key（pi52-ocr） |

## pi54 新店部署 SOP

### 前置確認（現場）
- [ ] pi54 本機 IP（`ip addr`）
- [ ] 印表機 IP（Epson 設定頁 or `arp-scan -l`）
- [ ] pi54 MAC 地址（`ip link show`）

### 部署步驟（在 pi53 執行）
```bash
# 1. 設定靜態 IP（在 pi54 上）
ssh pi54 "sudo nmcli con mod '有線連線' ipv4.addresses 192.168.x.x/24 ..."

# 2. fleet 一鍵部署 printer-proxy
cd /home/pi53/fleet
./deploy.sh pi54 printer-proxy
# post_deploy.sh 自動偵測 IP/MAC 寫入 proxy.py

# 3. 放 OpenAI API key
ssh pi54 "echo 'OPENAI_API_KEY=sk-proj-...' > ~/.env && chmod 600 ~/.env"

# 4. 確認印表機 IP 正確
ssh pi54 "grep PRINTER_IP ~/proxy.py"
# 若不同需手動修改
```

### 驗收
```bash
sudo systemctl status printer-proxy   # → active
ss -tn | grep 9100                     # → ESTAB 到印表機
# UberEats app 掃描 → 看到 TM-m30II
# 印一張測試單 ✅
```
