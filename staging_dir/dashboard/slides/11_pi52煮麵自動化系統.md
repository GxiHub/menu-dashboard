## 三、硬體架構

```
Raspberry Pi（pi52）
        │ USB（CH341 晶片）
        ▼
  /dev/ttyRS485 → /dev/ttyUSB0
  9600 baud, Modbus RTU
        │
        ├── Slave 0x01  電磁爐（5000W）
        ├── Slave 0x08  PT100 溫度感測器（CH1）　中盛科技
        ├── Slave 0x0B  繼電器模組一　　　　　　　中盛科技
        │               coil 0/1  → 推桿 1 伸/縮
        │               coil 2/3  → 推桿 2 伸/縮
        │               coil 4/5  → 推桿 3 伸/縮
        │               coil 6    → 風扇 1
        │               coil 7    → 風扇 2
        └── Slave 0x0C  繼電器模組二　　　　　　　中盛科技
                        coil 0/1  → 推桿 6
                        coil 4    → 風扇 3 ★自動溫控連動
                        coil 6/7  → 推桿 4/5
```

## 四、RS485 裝置規格（中盛科技模組）

### 共通通訊參數

| 項目 | 出廠預設 | pi52 系統 |
|------|---------|----------|
| 地址 | 1 | 依裝置 |
| 波特率 | **38400** | **9600** |
| 資料位 | 8 | 8 |
| 停止位 | 1 | 1 |
| 奇偶校驗 | 無 | 無 |

### 關鍵保持暫存器（兩款裝置相同，FC06 寫，掉電保存，重新上電生效）

| 暫存器 | 功能 | 預設 |
|--------|------|------|
| `0x0032` | **RS485 地址**（1~255） | 1 |
| `0x0033` | 波特率：0=4800 / **1=9600** / 4=38400 | 4 |
| `0x003D` | 奇偶校驗：0=無 / 1=奇 / 2=偶 | 0 |

### PT100 讀溫度（FC04，input register）

| 暫存器 | 功能 |
|--------|------|
| `0x0000` | CH1 溫度值 |
| `0x0001` | CH2 溫度值 |

- 最高位為符號（0=正 / 1=負），其餘 15 位 ÷ 10 = °C
- `0xFFFF` = 感測器未接入或斷路

### 繼電器線圈（FC01 讀 / FC05 寫）

- `FC05 FF00` = ON，`FC05 0000` = OFF
- Coil 從 0 開始（0-indexed）

## 五、新模組上線標準流程

> ⚠️ 出廠波特率 38400，pi52 用 9600，新模組插上 bus **不會有回應**。
> ⚠️ 建議**單獨接線設定**，不要直接並入 bus，避免影響其他裝置。

```
Step 1　以 38400 baud 連線 → 寫 reg 0x0033 = 1（改波特率為 9600）→ 斷電重啟
Step 2　以 9600 baud 連線  → 寫 reg 0x0032 = 目標地址             → 斷電重啟
Step 3　掃描 bus 確認新地址有回應
```

```python
import serial, struct, time

def crc16(data):
    crc = 0xFFFF
    for b in data:
        crc ^= b
        for _ in range(8):
            crc = (crc >> 1) ^ 0xA001 if crc & 1 else crc >> 1
    return crc

def fc06(ser, slave, reg, val):
    pkt = struct.pack('>BBHH', slave, 0x06, reg, val)
    pkt += struct.pack('<H', crc16(pkt))
    ser.reset_input_buffer()
    ser.write(pkt)
    time.sleep(0.4)
    resp = ser.read(8)
    ok = bool(resp and resp[0] == slave and resp[1] == 0x06)
    print(f'Slave 0x{slave:02X} reg 0x{reg:04X}={val} → {"OK" if ok else "FAIL"}')
    return ok

# Step 1：以 38400 改波特率為 9600
ser = serial.Serial('/dev/ttyRS485', 38400, timeout=1)
fc06(ser, 0x01, 0x0033, 1)
ser.close()
input('斷電重啟後按 Enter...')

# Step 2：以 9600 改地址
TARGET = 0x0C  # ← 修改為目標地址
ser = serial.Serial('/dev/ttyRS485', 9600, timeout=1)
fc06(ser, 0x01, 0x0032, TARGET)
ser.close()
input('斷電重啟後按 Enter...')
```

## 七、自動溫控邏輯

```
溫度 < 緩衝起點（預設 90°C）
        → 加熱功率（預設 78%）

緩衝起點 ≤ 溫度 < 保溫起點（預設 100°C）
        → 緩衝功率（預設 40%）

溫度 ≥ 保溫起點
        → 保溫功率（預設 15%）

最高功率上限：AUTO_MAX_PWR = 78%（硬限制）
```

## 八、一鍵加熱流程

```
設定水量（0.5L ~ 30L）
        ↓
按「▶ 開始」
        ↓
POST /api/temp_log/clear    ← 清除舊曲線
POST /api/auto_temp {enabled:true}  ← 自動溫控 ON
POST /api/fan {fan:3, on:true}      ← 風扇 3 ON
計時器啟動 + 溫度曲線開始記錄
        ↓
達到 100°C（或按重設）
        ↓
POST /api/auto_temp {enabled:false}
POST /api/fan {fan:3, on:false}
計時器停止
```

## 十、排錯備忘

| 現象 | 原因 | 解法 |
|------|------|------|
| 新模組完全無回應 | 出廠波特率 38400，系統用 9600 | 先用 38400 連線改波特率 |
| 修改後重啟仍是舊地址 | 未確實斷電（軟重啟無效） | 拔插電源 |
| 掃描收到錯誤地址的回應 | Bus 雜訊殘留 | 每次查詢前 `reset_input_buffer()`，間隔 ≥ 0.3s |
| PT100 讀到 0xFFFF | 探針未接或斷路 | 檢查 T+/T− 接線 |
| 繼電器 coil 編號混淆 | Coil 從 0 開始（0-indexed） | Coil 1 = index 0 |
| Tailscale 斷線 | VPN 掉線 | 改用 `pi52-local`（192.168.0.21） |
